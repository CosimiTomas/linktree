# SGV · Sistema de Gestión de Vacunas

Hub del proyecto **SGV** (Sistema de Gestión de Vacunas) para el vacunatorio del CAPS San José Obrero de Hurlingham, Buenos Aires.
Trabajo integrador del **Equipo N.° 01** de 7.° Informática B, Instituto Leonardo Murialdo, ciclo lectivo 2026.

La web del sistema: https://sgv.up.railway.app/
El código del sistema: https://github.com/CosimiTomas/SGV

## Sitio

Con GitHub Pages activado (Settings → Pages → rama `main`, carpeta `/ (root)`), el hub queda en:

**https://cosimitomas.github.io/linktree/**

## Estructura

```
linktree/
├── index.html              Hub del proyecto (linktree)
├── landing/                Página de presentación del SGV
├── docs/                   Documentación del proyecto (alcance, requisitos, casos de uso, bitácora)
├── tecnica/                Documentación técnica (recorrido del código y herramientas)
├── base-de-datos/          Resumen de la base de datos
├── manual/                 Manual de usuario, con capturas
├── quick-start/            Guía de inicio rápido
├── faq/                    Preguntas frecuentes
├── presentacion/           Prueba piloto y roadmap
└── README.md
```

Cada carpeta tiene su `index.html` y, si usa imágenes, su carpeta `img/`.

Contenido actualizado a la versión de noviembre de 2026 de la web.
